# Image-Invert-size-PWA
**https://aaban312.github.io/Image-Invert-size-PWA/**

decrease image size and invert

**Image Invert PWA — Key Advantages**

**Private by design**  
All processing happens in your browser. Photos never leave your device and are never uploaded to a server.

**True color inversion**  
White becomes black, black becomes white. Full negative mode also flips color channels; lightness-only mode keeps the original hue while swapping bright and dark areas.

**Gallery and camera, separate**  
Pick any photo from your gallery, or take a new one with the camera. No forced camera-only flow.

**Adjustable file size**  
Control the longest edge, JPEG/WebP quality, and output format. See the estimated size before you download.

**Works offline as a PWA**  
Install it on your home screen. After the first visit it can run without a network connection.

**No account, no ads, no tracking**  
Open the page, invert, download. Nothing to sign up for.

**Cross-platform**  
Works on phone and desktop in modern browsers. Same interface, same result.

**Fast and simple**  
One screen: choose image → invert → tune size → download. No learning curve.
